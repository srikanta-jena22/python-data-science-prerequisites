# 📘 My AI/ML Journey: Foundational Notebooks

Welcome to my personal AI/ML logbook! This repository is a collection of hands-on practice notebooks where I build a strong foundation in Python for data science and machine learning.  


## ✅ What I Learned

### 🔢 NumPy: The Numerical Backbone
**Goal:** Understand arrays, matrix math, and numerical operations.  

**Skills Gained:**
- Creating arrays (`array`, `arange`, `linspace`, `zeros`, `ones`)
- Indexing, slicing, and reshaping arrays
- Mathematical & statistical operations (`mean`, `std`, `dot`, `matmul`)
- Generating test data with `numpy.random`

**Notebook:** [Numpy_Practice.ipynb](./Numpy_Practice.ipynb)


### 🐼 Pandas: Data Handling Made Easy
**Goal:** Clean, explore, and manipulate real-world datasets.  

**Skills Gained:**
- Reading and writing datasets (`read_csv`, exporting CSV/XLSX)
- Data cleaning (`dropna`, `fillna`, renaming columns)
- Selecting data (`.loc`, `.iloc`)
- Aggregation & analysis (`groupby`, `pivot_table`)
- Merging multiple datasets  

**Task:** Explored and summarized the Titanic dataset.  
**Notebook:** [Pandas_Practice.ipynb](./Pandas_Practice.ipynb)

---

### 📊 Matplotlib: Custom Visualizations
**Goal:** Build fundamental plots and customize every detail.  

**Skills Gained:**
- Line charts, bar graphs, histograms, scatter plots
- Titles, labels, colors, markers, line styles
- Creating dashboards with multiple subplots  

**Notebook:** [MatPlotLib_Practice.ipynb](./MatPlotLib_Practice.ipynb)

### ✨ Seaborn: Beautiful, Statistical Plots
**Goal:** Visualize data effectively with less code.  

**Skills Gained:**
- Distribution plots (`histplot`, `kdeplot`)
- Comparing categories (`countplot`, `boxplot`, `violinplot`)
- Correlations & relationships (`heatmap`, `scatterplot`)
- Overview plots (`pairplot`, `jointplot`)  

**Task:** Visualized Titanic dataset relationships: survival, age, class, and gender.  
**Notebook:** [Seaborn_Practice.ipynb](./Seaborn_Practice.ipynb)


## 🌟 Why This Matters
This foundational work was more than learning library functions—it's about building a **practical toolkit for the full data science workflow**:

- **Pandas:** The data wrangling powerhouse
